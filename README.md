# 2026 Agent 应用学习资料

这个仓库保存本地 Agent 课程的文字稿、已有逐视频字幕、课件，以及面向企业垂类 Agent 岗位的学习记录。**视频未上传**。原视频仍在本机 `E:\learn_vedio\agent`。

## 从另一台电脑开始

1. 安装 Git 和 Git LFS，运行 `git lfs install`。
2. 克隆本仓库：`git clone https://github.com/gray5508/my_learn_2026.git`。正常克隆会下载 LFS 课件；若只有指针文件，再在仓库目录运行 `git lfs pull`。
3. 从 [12–16 周学习路线](学习记录/Agent应用开发学习路线与面试计划.md) 开始，按当前项目问题查 [六门课程导读](学习记录/六门课程总览与逐章导读.md)。
4. 用 [学习进度](学习记录/学习进度.md) 记录实际完成的章节、项目结果和待复习点。
5. 每日动手前打开 [逐周执行计划与第一周日程](学习记录/Agent逐周执行计划与第一周日程.md)，查看技术、课程、交付物和验收条件。当前任务均待执行，每周 15–20 小时暂为假设。
