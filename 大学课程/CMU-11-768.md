# CMU 11-768：AI Agents

官方课程：[11-768 主页](https://www.cmu-agents.com/) · [CMU 课程说明](https://lti.cs.cmu.edu/misc-pages/intranet-course-info.html)

截至 2026-11-23，课程介绍以 LLM Agent 为核心，涉及指令遵循、工具、记忆、任务分解，以及安全沙箱、凭证管理、人与 Agent 的互动；还延伸到长程任务、训练和研究问题。课程为研究生层级，官方说明要求熟悉神经语言模型训练。

## 与当前目标的关系

适合当作 Agent 原理和研究视角的补充。当前目标是 3–4 个月做出可演示、可评估的企业应用并准备面试，因此优先使用本地课程和 CS329Z 的工程与评估部分。11-768 不必从第一讲到最后一讲完整跟读。

## 按需选学

| 项目遇到的问题 | 选学方向 | 要形成的答案 |
| --- | --- | --- |
| 工具调用不稳定 | Tool Use、规划与执行 | 哪一步失败；用规则、模型还是人工修复。 |
| 长任务难以恢复 | 记忆、长程任务与环境交互 | 状态、上下文、检查点和停止条件如何设计。 |
| 需要浏览器或高权限工具 | 沙箱、凭证、安全 | 权限边界、审计与人工确认点。 |
| 基线效果仍不足 | 训练、搜索与研究主题 | 先用评估数据确认瓶颈，再考虑微调或更复杂方案。 |

训练算法和研究论文可留到项目核心链路稳定后。若时间紧，优先能回答面试里的工程问题：为什么需要 Agent、何时用固定工作流、如何评估、怎么控制工具权限与失败风险。
