# Stanford CS329Z：Engineering AI Agents

官方课程：[主页与目录](https://cs329z.stanford.edu/) · [课程项目](https://cs329z.stanford.edu/project.html) · [教学安排](https://cs329z.stanford.edu/logistics)

截至 2026-11-23，课程覆盖 Agent 基础、LLM 开发基础、RAG、工具调用、编排框架、Agent 设计模式、记忆、多 Agent、数据、评估和安全。课程强调从组件搭建到项目评估，也设置完整项目与作业。官网后续日程可能更新，以官网为准。

## 与当前目标的关系

这门课适合做企业垂类 Agent 项目的工程参照，尤其是“先明确问题与验收标准，再构建、评估和迭代”。可以跟随其中的组件练习，但不需要为了面试把论文阅读和全部讲座看完。

## 选学顺序

| 时机 | 选学内容 | 在项目中交付 |
| --- | --- | --- |
| 第 1–4 周 | Agent 基础、RAG、Tool Use & Function Calling | 售后政策检索、订单查询工具和结构化处理建议。 |
| 第 5–8 周 | Frameworks & Orchestration、Design Patterns、Memory | 可恢复的售后流程、人工审批和任务状态。 |
| 第 9–10 周 | Evaluation Fundamentals、LLM-as-Judge、Safety | 真实样本集、失败分类、人工复核和权限边界。 |
| 有明确需要时 | Multi-Agent、Optimization、Coding Agents | 只在单 Agent 基线暴露问题后做对比。 |

## 项目练习

把课程项目要求映射到“电商售后异常处理工作台”：写清用户和业务问题；设定 30–50 条样本与评估规则；展示带引用的建议、人工审批、失败回退；记录正确率、处理耗时、成本和人工修改率。面试时重点讲基线与迭代证据。
