# 六门 Agent 课程总览与逐章导读

这六门课共 770 节，适合按“做出一个能处理真实图片的垂类应用”来选学。现阶段最有价值的是图像输入、工具调用、结构化输出、检索、评估和人工复核；课程中的完整通用 Agent 平台、分布式协作与框架安装可以按项目需求再补。以下依据课程目录和转录整理，字幕中的 API 名称与代码细节需回看视频核对。

## 适合你的学习路线

1. **选一个视觉任务，定评价标准。** 从有真实图片、判定规则和愿意复核结果的场景入手，例如商品图片质检、设备照片巡检或图表截图审查。第一周只选一种图片、一类结论，留出 30–50 张未参与调试的样本。
2. **做图像到结构化结论的最小闭环。** 看小哲 48–58、63 节，MCP 全栈 3-6 至 3-8、4-5 至 4-9、9-6 至 9-10；把你的图像处理算法包装成工具，让 Agent 返回区域、证据、结论和不确定项。
3. **补知识检索与工具接口。** 看小哲 64–79、LangChain 102–120、MCP 全栈 7 章及 10 章；用少量领域规则/案例做检索，要求结论能追溯到规则和图片区域。编程智能体 11–12 章可作第二种实现参考。
4. **处理失败和人工复核。** 看小哲 40–41、55–58，LangChain 61–70，MCP 全栈 12 章及 16-6 至 16-11；把重试、停止、状态、权限和人工更正做成明确流程。
5. **最后做可试用产品。** 从 MCP 全栈 17–18 章挑上传、附件、工具轨迹、报告展示相关内容；看 Hermes 的会话/技能/看板作为界面参考。用真实样本测漏检、误报、人工修改率、耗时与单次成本，再决定是否加视频、多 Agent 或分布式服务。

如果你后续确定 Java 技术栈，把 SpringAI 4、6、7、10 章移到第 2–4 步；若用 Python，则以 MCP 全栈和 LangChain 为主。A2A 适合两个独立 Agent 服务确需互通的阶段；MCP 主要解决工具和数据接入，两者作用不同（[A2A 官方文档](https://a2a-protocol.org/v1.0.0/)、[MCP 官方 SDK 入门](https://py.sdk.modelcontextprotocol.io/get-started/first-steps/)）。

下面的“重点”表示当前垂类视觉 Agent 值得精看并动手，“选看”表示按技术栈或实际问题补，“略读”表示先看标题或结论即可。

## 后续制定个人计划时需要先定的三件事

1. **目标行业与样本**：你最容易拿到哪类图片、标注/判断规则和真实反馈？这决定视觉算法、RAG 文档与评估集。
2. **实现栈**：如果主力是 Python，先从 MCP 全栈 + LangChain 选课；如果主力是 Java/Spring，把 SpringAI 作为主实操。图像算法可保留 C++，通过轻量 API 或本地工具接入。
3. **每周可用时间与完成标准**：用“能在未见图片上输出带证据的报告，并允许人工纠错”作为第一里程碑，再按可用时间排周计划；不要用看完视频数当进度。
