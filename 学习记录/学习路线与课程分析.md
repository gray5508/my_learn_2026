## 最值得学的内容

1. **先把单 Agent 的闭环做可靠。** 小哲 48–59 节涉及规划、任务分解、工具调用、执行循环、重试、状态和记忆；MCP 课程 3-6、3-7 是 ReAct 思路与第一个单 Agent，9-6 至 9-10、9-12 至 9-15 是工具、结构化输出、规划/执行和状态回滚。做出可观察、可停止、可重试的单 Agent，比先搭多 Agent 更有用。
2. **让视觉能力成为实际工具。** MCP 课程 3-8 讲多模态对 Agent 的影响，4-5、4-7、4-8、4-9 讲图像输入、工具调用和结构化结果。把你已有的图像处理代码封装成 `检测区域`、`OCR`、`相似图检索`、`质量评分` 之类的确定性工具，再由模型选用和解释结果。
3. **接入业务知识并保留证据。** 小哲 63 节讲垂类 Agent，64–79 节讲 RAG、分块、召回、精排及幻觉；MCP 课程 7-2 至 7-7 和 10-4 至 10-10 讲外部工具与 MCP 接入。第一版只检索少量领域规则、样例和处理手册，回答附来源与图片区域，不必先建复杂向量平台。
4. **把可靠性和人工复核放在产品里。** 小哲 27、40–41、55–58、73–77 节涉及模型评估、提示注入、错误恢复和检索质量；MCP 课程 12 章是工具隔离，16-6 至 16-11 是消息、人类介入、记忆和规划执行联动。视觉结果中要显示置信程度、证据、失败原因，允许人更正。
5. **最后补上可用界面与部署。** MCP 课程 17-7 至 17-14、18-3 至 18-10 涉及会话、附件、工具调用轨迹与文件查看；19 章讲部署。先有端到端试用流程，再决定是否跟做整套 Next.js 界面。

## 可以暂缓的内容

- MCP 课程 14–15 章的 A2A 和完整分布式多 Agent：等出现两个独立 Agent 服务确需互通时再学。A2A 官方将其定位为独立 Agent 之间的互操作协议；MCP 更侧重工具和数据接入，二者解决的问题不同（[A2A 官方说明](https://a2a-protocol.org/v1.0.0/)、[MCP 官方 SDK 入门](https://py.sdk.modelcontextprotocol.io/get-started/first-steps/)）。
- MCP 课程 8 章的 Redis Streams、复杂后台任务，13–14 章的完整沙箱部署，以及 17–18 章全部前端细节：原型验证前只取必要部分。
- Hermes 课程 1–10 节的大量产品背景、安装与版本操作，以及其框架专属配置：作为体验材料，避免把产品说明当作核心技术路线。
- 小哲 17–32 节的模型训练原理与术语：有知识缺口再回看；当前目标是应用和评估，不是训练基础模型。

## 建议做的第一个产品

从你能拿到图片和判断标准的领域选一个小场景，做“**视觉证据复核助手**”：用户上传一张或一组图片，并选择任务；系统调用已有图像算法和视觉模型找到区域、OCR/识别对象，再检索领域规则或案例，输出结构化发现、证据位置、依据与不确定项，最后由用户确认或纠正。可选切入点是商品图片质检、设备照片巡检、图表/截图审查。第一版只选其中一个，优先选择你有真实样本与判定规则的领域。

最小工作流：`上传图片 → 确定任务 → 视觉工具取证 → 检索规则/案例 → 生成结构化报告 → 人工复核 → 保存更正`。多模态第一阶段是“图像 + 文本”，视频、实时流和多 Agent 可以等单图任务稳定后再加。

验收不要只看“能回答”：先留出 30–50 个未参与调试的真实样本，记录区域定位是否正确、结论是否与证据相符、漏检/误报、人工修改比例、单次成本和完成时间。用这些数据决定下一步是改图像模型、工具接口、检索还是提示词。对于没有证据的判断，系统应明确标为待复核。

## 六周学习与动手顺序

| 阶段 | 学习内容 | 当周产物 |
| --- | --- | --- |
| 第 1 周：定题和样本 | 小哲 48、52、55、63；MCP 课程 3-6 至 3-8 | 选一个领域和一种图片任务；收集样本、规则及失败样例；写清输入、输出、不可自动决定的边界。 |
| 第 2 周：单 Agent 与视觉工具 | MCP 课程 4-5、4-7 至 4-9、9-6 至 9-10 | 可上传图片、调用一个你已有的图像处理工具，返回 JSON 和图片证据位置。 |
| 第 3 周：知识与证据 | 小哲 64–69、73–77；MCP 课程 7-2 至 7-7 | 接入少量规则/案例，报告显示引用；用测试样本看召回与误判。 |
| 第 4 周：可靠性 | 小哲 40–41、55–58；MCP 课程 12-3 至 12-5、16-6 至 16-11 | 加错误恢复、权限边界、人工复核和更正记录；建立一份固定评估集。 |
| 第 5 周：可试用产品 | MCP 课程 17-7 至 17-14、18-3 至 18-10；Hermes 11–25、39–42 用作交互参考 | 做上传、证据标注、报告与复核页面，让真实用户独立完成一次任务。 |
| 第 6 周：评估和迭代 | 小哲 27、73–79；MCP 课程 19 章按需 | 对未见样本评估，记录错误类别和成本；只修正占比最高的两类问题，再决定是否部署。 |

核心原则：课程服务于原型。第 2 周就开始做真实图像任务；遇到具体卡点再回查对应视频、字幕和课件。若单 Agent 已能稳定完成任务，就不需要为了“像 Agent 产品”而强行加入 A2A 或多个角色。
